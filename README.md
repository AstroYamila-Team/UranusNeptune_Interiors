# Uranus Neptune Interiors

This repository contains the data presented in our paper: 'Reassessing planetary composition: evidence for rock-dominated envelopes in Uranus and Neptune', Vanesa Ramirez, Yamila Miguel, Saburo Howard, 2026.

The files with the data produced in this work and used to make the plots are:

Neptune_ice_rock_reos.csv: Interior models calculated for Neptune ice+rock model, adopting REOS for water and the SESAME Dry Sand EOS for the rocky component.

Neptune_ice_rock_ses.csv: Interior models calculated for Neptune ice+rock model, adopting the SESAME water EOS and the SESAME Dry Sand EOS for the rocky component.

Neptune_iceonly_reos.csv: Interior models calculated for Neptune ice-only model, adopting REOS for water..

Uranus_ice_rock_reos.csv: Interior models calculated for Uranus ice+rock model, adopting REOS for water and the SESAME Dry Sand EOS for the rocky component.

Uranus_ice_rock_ses.csv: Interior models calculated for Uranus ice+rock model, adopting the SESAME water EOS and the SESAME Dry Sand EOS for the rocky component..

Uranus_iceonly_reos.csv: Interior models calculated for Uranus ice-only model, adopting REOS for water..

COLUMN UNITS

mcore: Earth mass

p12: Mbar

T0: K

req: Km
